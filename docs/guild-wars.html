⚔️ What is a Guild War?

Guilds are communities on Convoke. You can create one or join an existing one, host your own games and spaces, keep a curated member list and a shared ban list, and rise through the boost ranks together. A Guild War is a head-to-head competition between two guilds.

Guilds and wars live on Convoke, so that is where you set one up. SpellBot's job is the matchmaking: it gets players seated in a game that counts toward a war that is already running.

🎯 Queue a war match

Run /war in your Discord server and pick the war you are playing for. The war option autocompletes from the wars that are live on Convoke right now, so start typing a war's name and choose it from the list rather than typing it out.

From there it behaves like /lfg: SpellBot posts a game other players can join, and creates the table once the seats fill. Every player who joins is in the war match.

If nothing appears in the autocomplete, there are no wars running on Convoke at the moment. SpellBot reads the live list every time you use the command.

🎛️ Options

/war takes the same extras as /lfg, so you can set up the match the way you want it:

  • war — which live Guild War the game counts toward. Required.
  • friends — mention people to join the game with you.
  • seats — how many players, from 2 to 8. Defaults to 4 if you leave it off.
  • format — the game format you want to play.
  • bracket — the commander bracket you want to play.
  • rules — any additional rules or requests for the game.

💡 Good to know

  • War games are always Convoke games. Guild Wars only exist on Convoke, so a war match is created there whatever service your channel normally uses.
  • Seats are capped at 2 to 8. That is the range Convoke allows for war matches, so SpellBot will not seat one outside it.
  • Wars have to be live. If the war has not started or has already finished it will not be in the autocomplete, and SpellBot will tell you the war is not available.

🛟 Questions?
